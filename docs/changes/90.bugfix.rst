Fixed the extraction of the Stokes components from the visibilities of ``pyvisgen``. The correlations were paired as ``[XX, XY, YX, YY]`` although ``pyvisgen`` provides them as ``[V_11, V_22, V_12, V_21]``, which gave a wrong Stokes I for polarised sources and wrong Stokes Q, U and V. The Stokes visibilities now follow the standard convention, e.g. :math:`I = (V_{11} + V_{22}) / 2`, and the factors of 2 and 0.5 that were added as workarounds in ``Gridder.from_pyvisgen`` and ``Gridder.from_ms`` are removed. ``Gridder.from_fits`` now uses the mean of the parallel hands instead of their sum, ``Gridder.from_ms`` uses the parallel hands of measurement sets with four correlations, and ``Gridder.from_uvh5`` scales the visibilities back if the file was simulated with ``normalize=True``.
